# URL Shortener

A monolithic URL shortening service built with **Spring Boot** and **PostgreSQL**. Short codes are generated by Base62-encoding the database ID, which guarantees unique codes without collision checks or retries.

> **Status:** V1 (core functionality). See the [Roadmap](#roadmap) for planned features.

---

## Features (V1)

- Shorten any long URL into a compact code
- Redirect from a short code to the original URL (HTTP 302)
- Collision-free short codes using Base62 encoding of the auto-increment ID
- Persistent storage in PostgreSQL with a unique index on the short code
- Dockerized database for easy local setup

## How It Works

1. A client sends a long URL to `POST /api/shorten`.
2. The service saves it to Postgres and receives an auto-increment ID.
3. The ID (plus an offset so codes aren't a single character) is encoded to Base62 (`0-9a-zA-Z`), producing a short code like `1Xk9`.
4. When someone visits `GET /{code}`, the service looks up the code in Postgres and redirects to the original URL.

**Why Base62?** Each character carries 62 possibilities, so 6 characters already cover about 56 billion URLs. Because every ID is unique, every code is unique, with no collision handling needed.

## API

### Shorten a URL

```http
POST /api/shorten
Content-Type: application/json

{
  "longUrl": "https://example.com/some/very/long/path"
}
```

**Response**

```json
{
  "shortCode": "1Xk9"
}
```

### Redirect

```http
GET /{shortCode}
```

Returns `302 Found` with a `Location` header pointing to the original URL, or `404 Not Found` if the code doesn't exist.

## Getting Started

### Prerequisites

- Java 17+
- Maven or Gradle
- Docker and Docker Compose

### Run locally

```bash
# 1. Clone the repo
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# 2. Start PostgreSQL
docker compose up -d

# 3. Run the application
./mvnw spring-boot:run
```

The app starts on `http://localhost:8080`.

### Try it

```bash
# Create a short URL
curl -X POST http://localhost:8080/api/shorten \
  -H "Content-Type: application/json" \
  -d '{"longUrl": "https://example.com"}'

# Follow the redirect
curl -i http://localhost:8080/<shortCode>
```

## Roadmap

This project is being built incrementally. Planned improvements:

- [ ] **User accounts**: register and manage your own links
- [ ] **Authentication and authorization**: secure login (JWT / Spring Security), with per-user link ownership
- [ ] **Analytics**: click counts, referrers, timestamps, and a top links endpoint
- [ ] **Rate limiting**: protect the API from abuse (token bucket or sliding window)
- [ ] **Redis caching**: faster redirects, benchmarked against the V1 baseline
- [ ] **Bloom filter**: cheaply reject codes that don't exist
- [ ] **Custom aliases and link expiry**
